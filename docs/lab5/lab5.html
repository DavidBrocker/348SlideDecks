Lab 5: The One-Sample t-Test

Testing a Sample Mean When σ Is Unknown

Dave Brocker

Farmingdale State College

Quick Recap

\[z = \frac{\bar{x} - \mu}{\sigma / \sqrt{n}} \qquad\qquad t = \frac{\bar{x} - \mu}{s / \sqrt{n}}\]

  • Last lab we knew the population standard deviation \(\sigma\), so we used z

  • Usually we do not know \(\sigma\), so we estimate it with the sample standard deviation \(s\) and use t

  • The t distribution has fatter tails than z, and it depends on the degrees of freedom: \(df = n - 1\)

  • Same habit as before: write every argument by name

Where Does \(s\) Come From?

\[s = \sqrt{\frac{\sum (x - \bar{x})^2}{n - 1}}\]

  • Numerator: every score’s squared distance from the mean, added up

  • Denominator: \(n - 1\), and then we take the square root

  • \(\dfrac{s}{\sqrt{n}}\) is the estimated standard error: how much sample means bounce around

Scenario

A national survey says college students spend 9 hours a week studying outside of class. We asked 12 PSY 348 students how many hours they studied last week.

  • \(H_0: \mu = 9\) (our students study the same as the national average)

  • \(H_A: \mu \neq 9\) (they study a different amount: a two-tailed test)

  • \(\alpha = .05\)

  • We do not know \(\sigma\), so this is a one-sample t-test

By Hand First

\[t = \frac{\bar{x} - \mu}{s/\sqrt{n}} = \frac{12.67 - 9}{4.72/\sqrt{12}} = \frac{3.67}{1.36} = 2.69\]

  • \(df = n - 1 = 12 - 1 = 11\)

  • The two-tailed critical value for \(df = 11\) is \(\pm 2.20\)

  • \(|2.69| > 2.20\), so we expect to reject \(H_0\)

Now in R: Step by Step

t_by_hand.R

mu_0 <- 9                                  # the value in H0
n    <- length(x = study_hours)
m    <- mean(x = study_hours)
s    <- sd(x = study_hours)

se   <- s / sqrt(x = n)                    # estimated standard error
t    <- (m - mu_0) / se
df   <- n - 1

# Two-tailed p: area beyond |t| in one tail, doubled
p    <- 2 * pt(q = abs(x = t), df = df, lower.tail = FALSE)

# Critical value: the t that leaves 2.5% in each tail
t_crit <- qt(p = 0.975, df = df, lower.tail = TRUE)

c(se = se, t = t, df = df, p = p, t_crit = t_crit)

Effect Size and APA Write-Up

\[d = \frac{\bar{x} - \mu}{s} = \frac{12.67 - 9}{4.72} = 0.78\]

cohens_d.R

d <- (m - mu_0) / s
round(x = d, digits = 2)
[1] 0.78

  • Students studied more than the national average of 9 hours, M = 12.67, SD = 4.72, t(11) = 2.69, p = .021, d = 0.78.

  • By the usual benchmarks, \(d \approx 0.8\) is a large effect
