The Takeaway

  • Summary statistics (mean, SD, correlation) can hide the actual shape of your data

  • Outliers, clusters, and non-linear patterns are often invisible in a table of numbers

  • Always look at the picture — it’s not optional, it’s part of the analysis

Choosing the Right Chart

A Quick Decision Guide
What are you showing? Best chart
bar_chart One categorical variable (counts per group) Bar chart
insert_chart One continuous variable (its shape/spread) Histogram or density plot
scatter_plot Two continuous variables (a relationship) Scatterplot
equalizer A continuous variable, compared across groups Box plot
show_chart Change over time Line chart

Every ggplot2 chart follows the same three-ingredient recipe — we’ll come back to this constantly this semester. It’s ggplot2’s implementation of Wilkinson’s “Grammar of Graphics”: any chart can be built from the same small set of parts.

Example Student Data

One Dataset, Several Questions

Build a fake ‘students’ dataset we’ll reuse all lecture 
set.seed(2)  # makes the "random" data reproducible every time this renders
students <- tibble(
  student = 1:60,                                             # just an ID number
  study_time = sample(c("Morning", "Afternoon", "Evening", "Night"), 60,
                       replace = TRUE, prob = c(0.15, 0.30, 0.35, 0.20)),   # categorical variable
  study_hours = pmax(round(rnorm(60, mean = 6, sd = 2), 1), 0.5),          # continuous variable, floor at 0.5
  study_method = rep(c("Flashcards", "Practice Tests"), each = 30),       # two even groups
  exam_score = pmin(round(55 + 2.5 * study_hours +                        # score rises with study hours...
                     ifelse(study_method == "Practice Tests", 4, 0) +     # ...gets a small bump from practice tests...
                     rnorm(60, 0, 5)), 100)                               # ...plus random noise, capped at 100
)

readr::write_csv(students, "students.csv")  # so it can be linked/downloaded below

How Graphs Can Mislead

Same Data, Different Story

Same exact numbers. The right panel makes a small difference look dramatic — always check where the y-axis starts.

Building a Good Graph

  • Title — what am I looking at?

  • Labeled axes — with units, if relevant

  • An honest scale — start bar charts at 0; don’t cherry-pick a range to exaggerate a difference

  • Only the elements that add information — no 3D effects, no unnecessary gridlines, no clutter
